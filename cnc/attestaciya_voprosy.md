# Вопросы и ответы — теоретическая часть (ЧПУ)

По учебному пособию: Лебедев А.Р., Исаев А.Н., Гавриленко М.Д.  
«Технологии программирования станков с компьютерным управлением» (ДГТУ, 2016).

Ответы короткие — для итогового чтения.

---

## 1. Основы ЧПУ

**1. Что такое ЧПУ?**  
Компьютерная система, которая управляет приводами станка (подачи, шпиндель, автоматика) по программе.

**2. Чем отличаются NC и CNC?**  
- **NC** — старые системы, программа на внешних носителях, без гибкого процессора.  
- **CNC** — современные системы на микропроцессоре: программу можно писать, менять и хранить в памяти.

**3. Из чего состоит система ЧПУ?**  
Пульт оператора, дисплей, контроллер (интерполятор), ПЗУ, ОЗУ.

**4. Что делает контроллер (интерполятор)?**  
Считает траекторию инструмента, выдаёт команды приводам и автоматике станка.

**5. Что такое интерполятор?**  
Устройство/программа, которая по конечным точкам считает промежуточные точки пути (прямая, дуга).

**6. Какой язык программирования самый распространённый?**  
**G-код** (стандарт ISO 6983).

**7. Какие есть 3 метода программирования станков с ЧПУ?**  
1) Вручную  
2) На пульте УЧПУ  
3) Через CAD/CAM

## 2. Структура управляющей программы

**8. С чего начинается и чем заканчивается УП?**  
Начинается с **`%`**, заканчивается **`M30`** (или `M02`) и снова **`%`**.

**9. Что такое кадр программы?**  
Одна строка команд. Состоит из блоков (адрес + число), например `G01 X50 Y20 F80`.

**10. Что такое адрес?**  
Буква команды: `G`, `M`, `X`, `Y`, `Z`, `F`, `S`, `T` и т.д.

**11. Можно ли в одном кадре два одинаковых адреса (кроме G)?**  
Обычно **нет**. `G` можно повторять, если они из разных групп и не противоречат друг другу.

**12. Для чего нужны подпрограммы?**  
Чтобы не повторять одинаковые куски кода. Вызов — из основной программы, конец подпрограммы — `M99`.

**13. Что такое постоянные циклы?**  
Готовые типовые циклы в памяти ЧПУ (сверление, расточка, резьба и т.п.), например `G81`, `G76`.

## 3. Системы координат

**14. Что такое «ноль станка»?**  
Исходное положение осей после выхода в референсные точки (HOME / REF).

**15. Что такое «ноль детали» (G54…G59)?**  
Точка отсчёта на заготовке. Программа работает относительно неё.

**16. Чем G54 отличается от G53?**  
- **G54–G59** — системы координат **детали**  
- **G53** — координаты **станка**

**17. Что такое программируемая точка (ПТ)?**  
Точка инструмента, которую ведут по программе (обычно центр/острие/режущая кромка с учётом коррекции).

**18. Чем отличаются G90 и G91?**  
- **G90** — абсолютные координаты (от нуля детали)  
- **G91** — относительные (от предыдущей точки)

## 4. Перемещения и интерполяция

**19. Что делает G00?**  
Быстрый холостой ход (позиционирование). Траектория по нескольким осям не гарантируется «по прямой».

**20. Что делает G01?**  
Рабочая прямая на подаче **F**.

**21. Что делают G02 и G03?**  
Движение по дуге:  
- **G02** — по часовой  
- **G03** — против часовой

**22. Что такое плоскость интерполяции?**  
Плоскость, в которой идёт совместное движение по двум осям:  
- **G17** — XY (по умолчанию)  
- **G18** — XZ  
- **G19** — YZ

**23. Как задать центр дуги?**  
Адресами **I J K** (смещение центра от начальной точки): I→X, J→Y, K→Z.  
Либо радиусом **R** (для полной окружности R нельзя).

**24. Как задаётся подача?**  
- **G94** — мм/мин (обычно для фрезерования)  
- **G95** — мм/об (часто для точения)

---

## 5. Инструмент и коррекция

**25. Что делают T и M06?**  
`T` — номер инструмента, `M06` — смена инструмента.

**26. Что такое радиусная коррекция?**  
Смещение траектории на радиус фрезы:  
- **G41** — слева от контура  
- **G42** — справа  
- **G40** — отмена

**27. На чём включают и снимают G41/G40?**  
На **прямой** (`G01`), не на дуге.

**28. Что такое коррекция длины инструмента?**  
`G43` (+ `H`) — учёт длины инструмента по оси Z.

---

## 6. Вспомогательные функции (часто на аттестации)

**29. Что делают основные M-команды?**  
- **M03** — шпиндель по часовой  
- **M04** — шпиндель против часовой  
- **M05** — стоп шпинделя  
- **M08 / M09** — СОЖ вкл/выкл  
- **M30** — конец программы и возврат в начало

**30. Что делает S?**  
Задаёт обороты шпинделя (об/мин).

**31. Что делает F?**  
Задаёт подачу.

---

## 7. HAAS (по главе 1 пособия)

**32. Сколько координат может управлять УЧПУ HAAS (по пособию)?**  
До **5**, одновременно по **3**.

**33. Нужна ли нумерация кадров N в HAAS?**  
По пособию — **не обязательна** (в отличие от многих других стоек).

**34. Чем удобны переменные в УП?**  
Можно менять размеры/повторы без переписывания всей программы.

---

## 8. Программирование высокого уровня (GTL)

**35. Что такое GTL?**  
Геометрический технологический язык: описываешь прямые и окружности «как на чертеже», а система сама считает точки касания/пересечения.

**36. В каком режиме работает геометрия GTL?**  
Только в **G90** (абсолютные координаты).

**37. Какие основные геометрические элементы в GTL?**  
Начало отсчёта, точка, прямая, окружность.

## Мини-шпаргалка G/M

| Код | Смысл |
|-----|--------|
| G00 | Быстро |
| G01 | Прямая на подаче |
| G02 / G03 | Дуга CW / CCW |
| G17 / G18 / G19 | Плоскость XY / XZ / YZ |
| G40 / G41 / G42 | Отмена / коррекция слева / справа |
| G54…G59 | Ноль детали |
| G90 / G91 | Абсолют / приращение |
| G94 / G95 | мм/мин / мм/об |
| M03 / M05 | Шпиндель вкл / стоп |
| M06 | Смена инструмента |
| M08 / M09 | СОЖ |
| M30 | Конец программы |

## 3. Управляющая программа (один проход)

Файл УП: [`var10.nc`](var10.nc) (программа **O0010**).

### Принятые исходные данные

| Параметр | Значение | Примечание |
|----------|----------|------------|
| Фреза | концевая Ø16 мм | диапазон задания 10…30 мм |
| Корректор радиуса | D1 = 8.0 | половина диаметра |
| Корректор длины | H1 | через **G43** |
| Глубина | Z−5 | один проход |
| Врезание | F60 | |
| Контур | F100 | |
| Шпиндель | S1800 M03 | |
| Коррекция диаметра | **G41** | обход по часовой, инструмент слева снаружи |
| Отмена | **G40** только на **G01** | |

### Схема программы

1. `G21 G17 G40 G49 G80 G90`, `G54`, `T1 M06`, `S1800 M03`.
2. Подвод к точке захода справа от точки 1.
3. `G43 H1` — коррекция длины, подвод по Z.
4. Врез `G01 Z-5`.
5. `G41 D1` на прямой, дуга захода `G03` на контур.
6. Обход контура: прямые `G01`, дуги `G02`/`G03` с I/J.
7. Дуга выхода, отвод, `G40` на `G01`.
8. Подъём, возврат в ИП `(0, 0, 300)`, `M30`.

## 4. Защита работы (устно, 2–3 предложения)

Я взял фрезу диаметром 16 мм — это в середине диапазона 10–30 мм, и в корректор D1 удобно поставить радиус 8 мм. Глубину сделал 5 мм одним проходом, длину включил через G43 H1 при подводе по Z.

Контур обхожу по часовой с G41, чтобы фреза шла снаружи слева от траектории; G40 снимаю только на прямом кадре после выхода, иначе стойка ругается. Заход и выход — касательными дугами справа от точки 1, чтобы коррекция успела набраться до первого участка контура.

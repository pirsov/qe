# Контур детали для симулятора ЧПУ

Управляющая программа фрезерования замкнутого контура по чертежу (радиусы R60, R55, R115, R145, R116). Стойка — **Fanuc / ISO**.

## Как загрузить в симулятор

1. Откройте `cnc/duck.nc` (Fanuc mill, плоскость G17, мм).
2. Инструмент **T1**, фреза **Ø8 мм**. В регистр коррекции **D1 занесите радиус 4.0 мм** (не диаметр). Если стойка хранит в D диаметр — поставьте 8.
3. Нуль детали **G54**:
   - **X = 0** — вертикальная штриховая ось на чертеже;
   - **Y = 0** — нижняя штриховая линия размера 150;
   - **Z = 0** — верх заготовки.
4. Заготовка (с запасом): **X −200…325, Y −180…270, толщина 10 мм**. Глубина в УП: **Z−5**.

Подходит для CNC Simulator, NC Viewer, CAMotics, LinuxCNC, Fanuc NCGuide.

## Что делает программа

- **Заход с детали.** Подвод снаружи справа от P2, опускание на Z−5, **G41** на прямой, затем дуга **G03 R20** на контур (касательно вниз).
- **Контур** по часовой: голова → шея R55 → грудь 25° → спина R115 и 5° → хвост → R116 → низ → брюхо R145 → левая сторона 80° → R60.
- **Выход с детали.** Дуга **G03 R20** с контура наружу, отвод от детали, затем **G40 только на G01** (не на дуге — иначе SwanSoft выдаёт ошибку), подъём, парковка.

Дуги заданы **G02/G03 + I J** (приращения до центра). Все дуги короче 180°.

## Размеры с чертежа

- 85 — X центра R60 (центр в (−85, 200))
- 200 — вертикальный пролёт левой стороны 80°
- 150 — Y стыка головы и R55
- 305 — X хвоста
- 5° — спина, вверх вправо
- 25° — грудь, вниз вправо
- 80° — левая сторона к горизонту
- 120° на чертеже — внешний угол у хвоста (внутренний 60°), нижняя линия хвоста под **65°** к +X

Пересчёт:

```bash
python3 cnc/generate.py
```
